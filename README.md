This project is for an application that is accessed via a web browser, also known as a Progressive Web Application. The main purpose of this application is to
store recipes in a virtual recipe book. It also allows the user to utilize AI to generate several things related to recipes and meals.

The user creates a personal user account, but users are also able to create a family of users. Users within the same family are able to share recipes,
pantries, and weekly meal plans together. A user is able to create and store their own recipes, pantry items, and weekly meal plans. The user is also
able to send a prompt to an AI model within the application, and the AI can use that prompt to generate a recipe or a weekly meal plan from currently
stored recipes.

The application is built using the Flask framework in Python for the backend and the communication with a database. My hosting uses Supabase as the database host,
Render hosts the backend, and CloudFlare hosts the frontend. The frontend uses HTML, TailwindCSS, and Typescript.
